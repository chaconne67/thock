Thock의 첫 공개판입니다. CapsLock으로 Windows의 어느 입력창에서나 말을 받아 적습니다.

## 설치

1. 아래 `Thock-setup-x64.exe`를 내려받아 실행합니다.
2. 관리자 권한 없이 `%LOCALAPPDATA%\Programs\Thock`에 설치되고 바로 시작합니다. 로그인할 때마다 자동으로 시작합니다.
3. 처음 켜면 설정 창이 열립니다. Soniox 키를 붙여 넣고, "연결"에서 ChatGPT로 로그인하거나 OpenRouter 키를 넣습니다.

서명하지 않은 설치 파일이라 Windows SmartScreen이 경고할 수 있습니다. "추가 정보 → 실행"을 누르면 설치됩니다.

## 이번 판에 든 것

- **누르고 말하기 / 켜 두고 말하기**: CapsLock을 누른 채 말하거나, 짧게 눌러 켜고 다시 눌러 끝냅니다. 대문자 고정은 Shift+CapsLock.
- **실시간 인식과 교정**: Soniox 실시간 인식 뒤 교정 모델이 글을 다듬어 커서 위치에 붙여 넣고, 원래 클립보드를 되돌립니다.
- **말투 맞추기**: 말한 말투를 따르고, 반말과 존댓말이 섞이면 더 많이 쓴 쪽으로 맞춥니다.
- **Thock이 아는 나**: 받아쓰기가 쌓이면 분야·주제·자주 쓰는 말을 파악해 인식과 교정에 씁니다.
- **오타 노트**: 붙여 넣은 글을 직접 고치면 기억해 두었다가 다음부터 반영하고, 세 번째부터는 자동으로 바꿉니다.
- **작은 막대**: 작업 표시줄 위에 떠서 듣는 중·교정 중·실패를 보여 줍니다. 끌어서 옮기고, 톱니바퀴나 오른쪽 클릭으로 설정을 엽니다.

## 알아 둘 점

- 관리자 권한으로 실행한 창에서는 동작하지 않습니다(Windows 보안 규칙).
- 설정과 기록은 `~/.voicetype/`에 있고, 제거해도 남습니다. 음성은 저장하지 않습니다.
